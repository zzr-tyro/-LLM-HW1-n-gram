```

        │         ├──► 留出集困惑度 PPL 对比
        │         ├──► 归一化自检（Σp(w|ctx) 是否 ≈ 1）

```

## 为什么必须清理所有多余的 tag？（PPT 第 11 页的问题）

语料是“切分标注版”，但 n-gram 语言模型只关心**词的表层形式**：

1. **注音标注 `{shang5}` 是黏在词上的**：`上{shang5}` 与 `上` 会被当成两个完全不同的
   token → 同一个词的计数被分散成多份，词表虚胖，稀疏问题雪上加霜（本次清洗共去掉
   87,189 处注音）。
2. **行号 ID 会污染上下文**：`19980101-01-001-001` 若不剥离，会被当作普通词参与计数，
   甚至成为“最频繁词”之一，浪费概率质量、干扰生成。
3. **（若含词性标签）`的/u` ≠ `的`**：POS 是额外的监督信息，不属于“下一个词是什么”
   这个语言模型任务建模的对象；保留它等于把词表翻倍、把稀疏再放大一个量级。
4. 全角数字 `１２` 与半角 `12` 若不归一，同样是“同一个词被拆成两个”的问题。

一句话：**清理 tag = 把语料还原为“干净的分词文本”，让统计集中在真正的词上。**

## 实验观察点（预期结果）

| 现象 | 解释 |
| --- | --- |
| MLE 的 PPL = ∞ | 测试集必有训练未见过的 n-gram，概率连乘被 0 拉爆（“稀疏与未见事件问题”） |
| Laplace 的 PPL 非常高，且随 n 增大恶化 | 词表 V 有数万，add-1 把大量质量“白送”给从未出现的组合，分布被压平 |
| PPL 排序：MKN < KN < Katz < JM < Laplace < MLE | 改进 KN 的分段折扣 D1/D2/D3+ 比单一折扣更精细；Katz 逐阶回退略逊于 KN 的插值 |
| 训练时间随 n 线性增长，n-gram 类型数近似指数膨胀 | 计数是 O(词数×n)；但表大小 ≈ O(\|V\|^n)——存储与稀疏才是真瓶颈 |
| 归一化自检 Σp(w\|ctx) ≈ 1.0000（MKN 修复前 0.8574） | 回退/插值实现必须质量守恒：γ 的折扣项与折扣方案必须配套，否则分布泄漏 |
| n 越大生成越“通顺”，温度越高越“放飞”；贪婪易陷入循环 | 高阶上下文提供更强局部约束；MLE/Laplace 的贪婪在未见处走投无路或自锁 |
| NLTK 与自实现 KN 的 PPL 接近（差约 9%） | 余差来自低阶折扣口径：我们按各阶 n1/n2 计 D，nltk 全阶统一 D 且低阶用原始计数——插值 KN 实现正确的直接证据 |

## 思考题参考解答（PPT 第 12 页）

### 1. 为什么 KN 要看“续接多样性”而不是词频？

回退时低阶分布要回答的问题是：**“这个词有多适合作为一段话的续接？”**
MLE unigram 回答的却是“这个词全局出现得多频繁？”两者不是一回事。

经典例子：`Francisco` 频数不低，但它几乎只跟在 `San` 后面——它作为“新续接”的能力
极差。若回退用普通词频，任何没见过的高阶组合都会把质量灌给 `Francisco` 这类词；
KN 用**续接计数** `|{w′ : c(w′, w) > 0}|`（w 前面出现过多少种不同的词）度量“续接
多样性”，把回退质量优先给 `glasses` 这种到处都能接的词。这也是 KN 在几乎所有
基准上优于 Katz/JM 的核心原因。

### 2. JM、Katz 与 KN 谁更“工程友好”？

- **JM（线性插值）**：实现最简单（几个 λ 加权求和），训练/查询都可并行，参数少、
  可 EM 估计；缺点是 λ 的选择敏感，且没有区分“词频”与“续接能力”。**工程最友好**。
- **Katz（回退+折扣）**：需要 Good-Turing 折扣 + 递归回退，n_r 缺失时还要退化处理；
  收益是概率质量更集中（不像插值那样对每条证据都打折），存储省。
- **KN**：效果最好，是 SRILM/KenLM 事实标准，但实现最复杂（续接计数、逐阶折扣、
  递归回退）。工程上值得为效果买单；教学上最值得读懂。

所以工程友好度 JM > Katz > KN，效果则恰好相反：KN > Katz > JM。

### 3. 依赖问题的根本原因和目的是什么？

**根本原因**：把 `P(w | 历史)` 参数化后，参数空间随历史长度指数爆炸
（O(|V|^n)），而任何有限语料都只能覆盖其中极小一角——**数据稀疏与参数规模之间的
根本矛盾**。n-gram 的 (n−1) 阶马尔可夫假设是这一矛盾下的折中：截断历史，换取
“计数→归一化”的简单可估性。

**目的**：在可承受的存储/计算代价内，得到一个能对任意词序列打分和采样的概率模型；
同时它把“语言 = 下一个 token 的条件分布”这一任务形式固定下来，为之后的平滑、
类共享、神经化铺路——后面所有模型都在回答同一个问题，只是换了参数化方式。

### 4. 如果无限增大 n，做成“∞-gram”，能解决长依赖吗？

**不能。** 三个层面：

1. **统计上**：n→∞ 时，语料中绝大多数“完整历史”只出现一次——计数全是 1 或 0，
   MLE 退化成“记忆训练集”，测试集上任何略有不同的历史都是 OOV，泛化为零。
2. **计算上**：历史组合数 |V|^t 指数爆炸，存储、检索、构建都不可行（这也是 n-gram
   需要剪枝、trie、量化等工程技巧的原因）。
3. **原理上**：长依赖需要的不是“更长的字面记忆”，而是**组合泛化**——把历史压缩成
   连续语义表示，使从未见过的历史也能映射到合理的下一个词。这正是神经语言模型/
   自注意力取代 n-gram 的根本动因（PPT 中 “The soups … were …” 的例子：再长的
   固定窗口也覆盖不了任意插入的从句）。
