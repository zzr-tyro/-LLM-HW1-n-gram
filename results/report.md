# 人民日报 n-gram 语言模型实验报告

## 1. 数据与清洗

- 语料：1998 年 1—6 月《人民日报》切分标注版（“带音”版本），GBK 编码，共 123,761 句

- 清洗内容：行号 ID（日期-版次-文章-句号）、多音字注音 `{shang5}` 式标注、全角数字归一化。**为什么必须清洗**：若不清洗，`上{shang5}` 与 `上` 会被当成两个不同的词，计数被分散、词表虚胖、稀疏加剧；行号 ID 会被当成普通词参与 n-gram 计数，污染上下文。


## 2. 训练时间对比

| n | 计数用时(s) | n-gram 类型数 |
| ---: | ---: | ---: |
| 2 | 2.8 | 38,568 |
| 3 | 7.1 | 660,532 |
| 4 | 11.7 | 1,990,660 |

> 观察点：n 每 +1，类型数通常膨胀一个量级（近似 |V|^n 的指数增长），而计数耗时只线性增长——**存储与稀疏才是 n-gram 的真正瓶颈**。


## 3. 困惑度对比（留出测试集）

| 方法 \ n | 2 | 3 | 4 | 说明 |
| --- | ---: | ---: | ---: | --- |
| mle | ∞ | ∞ | ∞ | 不平滑：未见过即 0 概率 |
| laplace | 3,940.47 | 19,385.58 | 30,534.02 | add-1：概率被压平 |
| jm | 448.87 | 396.49 | 396.09 | JM 插值，λ 由 EM 估计 |
| katz | 422.74 | 367.37 | 376.78 | Katz 回退 + GT 折扣 |
| kn | 404.37 | 327.93 | 318.51 | 插值 Kneser-Ney |
| mkn | 399.17 | 320.87 | 311.78 | 改进 Kneser-Ney（D1/D2/D3） |

> 观察点：MLE 的 PPL 为 ∞（测试集里必然出现训练未见的组合，概率连乘被 0 拉爆）；Laplace 因词表巨大（数万）被过度压平，PPL 极高；KN/MKN 通常最好。

## 5. NLTK 对照（验证自实现）

- 子集规模：训练 90,305 词，测试 9,740 词，order = 3

| 模型 | 训练时间(s) | PPL |
| --- | ---: | ---: |
| nltk MLE | 0.9 | inf |
| nltk Laplace | 0.9 | 8,253.02 |
| nltk KneserNeyInterpolated | 0.9 | 390.31 |
